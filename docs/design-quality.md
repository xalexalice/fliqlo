## v1.4.0 设计自检

Still 的设计方向是一间安静的时钟陈列室：苔绿底色、纸张色、清晰的大字号，以及精细的作品框架。画廊以稳定编号呈现收藏，每款时钟保留自己的视觉性格。

以用户提出的八项标准逐页检查。[Webby 评审标准](https://www.webbyawards.com/judging-criteria/)强调视觉、导航、功能、交互与整体体验的结合；[Awwwards 移动端指引](https://www.awwwards.com/mobile-excellence-guidelines.pdf)用于检查可读性、触控和视口适配；[FWA](https://thefwa.com/about)作为创意参考。这些是设计目标与审查依据，不代表已经获得奖项。

| 维度 | 改进与验证 |
| --- | --- |
| 排版 | 放大正文与辅助信息；衬线标题与功能性无衬线文字形成层次。小屏幕下的德语长标题可自然换行。 |
| 留白 | 统一桌面与手机的页面边距、区块节奏、卡片内边距及详情页间距。各尺寸下预览框保持比例。 |
| 视觉层级 | 页面标题、主要打开按钮与次要信息明确区分。筛选和排序时保留时钟编号。 |
| 色彩 | 苔绿、纸张色与克制的浅绿色强调色统一画廊。正文、辅助说明及 Dawn、Mono 的日期与标题颜色对比均超过 4.5:1。时钟保留各自配色。 |
| 动效 | 入场、弹窗与悬停反馈采用短时透明度、位移动画。系统启用减少动态效果时关闭这些动效，原版增强副本同样支持。 |
| 微交互 | 导航当前状态、键盘焦点、按压反馈、收藏状态与复制反馈均可辨认。主要画廊控件与原版增强工具栏触控高度至少 44px。 |
| 响应式 | 19 个网站页面在七种语言、320px 宽度下检查；离线钟检查 320×568、375×667、667×375、812×375、1024×600、1280×720。辉光管始终横排，原版增强控件会在窄屏换行。 |
| 原创性 | 编号陈列、柔和衬线标题与六管横排辉光钟形成一致的设计表达。玻璃反光、金属底座与琥珀光晕重新组合；MIT/OFL 来源与许可继续保留。 |

首轮改善辅助信息过小、间距不一致与竖版辉光管拥挤的问题。后续检查修复手机首页双栏、德语长标题和 Bubble 短屏溢出；原版增强工具栏扩大触控区域，并为设置抽屉留出空间。主要页面类型和全部时钟已查看桌面、手机实际截图。

验证通过：111 项浏览器回归检查、8 项单测、静态检查与构建校验。覆盖走时、背景、全屏、自动隐藏、多语言、收藏与分享。原版增强控件另在真实在线样式下检查不同宽度的触控区域和遮挡情况。

原始 fliqlo.html 保持字节不变；增强副本保留原主题，增加键盘焦点、减弱动效与触控布局优化。

## v1.5.0 蒸汽机械与 AM/PM 自检

辉光管保留六管横排，重新组合黄铜拉丝机箱、螺钉、齿轮观察窗、铜管、压力表和双烟囱蒸汽。齿轮慢速反向转动，蒸汽柔和飘散，装饰压力针轻微摆动；读时数字保持稳定。首页和详情预览使用同一份结构，预览动效静止，避免画廊出现多个持续运动的装饰。

所有时钟在 12 小时制下可选择显示或隐藏 AM/PM。新设置保存到原有每款时钟的设置中；24 小时制隐藏该开关，切回 12 小时制保留偏好。指针款同样提供此入口，原版增强款沿用设置抽屉中的既有开关。读屏时间继续保留上午/下午信息，避免隐藏视觉标签后产生歧义。

AM/PM 与日期共用信息行，七种语言的工具栏可自动换行。检查并修复 320px 小屏和短横屏下新增控件造成的空间不足。启用减少动态效果后，蒸汽、齿轮和压力针均静止，保留完整机械外观。

验证通过：126 项浏览器检查、8 项单测、静态检查和构建校验。新增检查覆盖全部 14 款的 AM/PM 偏好、午夜/正午边界、七种语言、刷新与格式切换，以及机械动效和减少动态效果。原始 HTML 保持字节不变。
